# Power BI Dashboard – Setup Guide

This document describes how to connect the Excel data file to Power BI Desktop
and build the eight telemetry charts.

---

## 1. Prerequisites

- [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free)
- `data/sample_telemetry.xlsx` (generated by `scripts/generate_sample_data.py`)

---

---

## 3. Import Data into Power BI

1. Open **Power BI Desktop**.
2. Click **Home → Get Data → Excel Workbook**.
3. Browse to `data/sample_telemetry.xlsx` and click **Open**.
4. In the Navigator, select the **Telemetry** sheet and click **Transform Data**.
5. In the **Power Query Editor**:
   - Expand **Home → Use First Row as Headers** if headers are not already promoted.
     *(Since row 1 is the header row and row 2 contains units, you may need to
     remove the first row using **Home → Remove Top Rows → 1** after promoting
     headers, to eliminate the units row.)*
   - Click **Close & Apply**.

---

## 4. LAPTIME Conversion (MM.SS.mmm → SSS.mmm)

In Power Query (M formula) add a **Custom Column** named `LAPTIME_s`:

```m
let
    raw   = Text.Trim([LAPTIME]),
    parts = Text.Split(raw, "."),
    mm    = Number.FromText(parts{0}),
    ss    = Number.FromText(parts{1}),
    mmm   = Number.FromText(parts{2}) / 1000
in
    mm * 60 + ss + mmm
```

This converts e.g. `"1.23.456"` → `83.456` seconds.

## 5. Create the Eight Charts

For every chart: select a **Line chart** visual, set:

- **X-axis** → `LAP`
- **Y-axis** → the column(s) listed below

| # | Chart Title            | Y-axis series                              |
|---|------------------------|--------------------------------------------|
| 1 | Lap Time               | `LAPTIME_s` (custom column, label "LAPTIME") |
| 2 | Fuel per Lap           | `FUEL/LAP`                                 |
| 3 | Water Temperature      | `T wat, Max` · `T wat, avg`                |
| 4 | Oil Temperature        | `T oil, Max` · `T oil, avg`                |
| 5 | Oil Pressure           | `Poil, Min` · `Poil, avg`                  |
| 6 | Alternator Voltage     | `Alt V, Min` · `Alt V, avg`                |
| 7 | Fuel Pressure          | `Pfuel, Min` · `Pfuel, avg`                |
| 8 | Lift Pump Current      | `LiftPump1 current, avg` · `LiftPump2 current, avg` |

> **Tip:** Format the Y-axis of chart 1 with a custom tooltip like `"#,0.000 s"` to show
> millisecond precision.
